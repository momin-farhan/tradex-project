# AI Usage
## Tools Used

### ChatGPT

ChatGPT was used as a development assistant during the assignment.

Purpose:
- Understand the assignment requirements
- Plan the Django project structure
- Generate and explain code
- Debug errors
- Develop the box recommendation logic
- Create automated tests
- Prepare project documentation
- Explain implementation decisions

## Prompts Used

The following prompts were used during development:

1. "Explain how I should demonstrate this assignment."

2. "I need to complete this assignment from scratch to done."

3. "Help me set up the Django project and virtual environment."

4. "Help me build the product, box, order, and order-item models."

5. "Help me implement the box recommendation algorithm."

6. "Help me test the recommendation logic with automated tests."

8. "Explain the errors I encounter and help me fix them one step at a time."

## What I Learned

Through this assignment, I learned how to:

- Set up a Django project using a virtual environment.
- Create Django models for products, boxes, orders, and order items.
- Use Django migrations to create database tables.
- Register models in the Django Admin panel.
- Separate business logic from views using a service module.
- Implement box selection based on product dimensions and weight.
- Select the cheapest suitable box.
- Create JSON endpoints in Django.
- Write automated tests using Django's TestCase framework.
- Use Git and GitHub to manage and synchronize the project.
- Debug Python indentation and Django configuration errors.
- Use AI as a development assistant while understanding and reviewing the generated code.
